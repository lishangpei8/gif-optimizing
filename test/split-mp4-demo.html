📋 方案介绍

RGB+Alpha拼接方案是一种将带透明度的GIF动图转换为普通MP4视频的优化方案。 该方案将GIF的RGB颜色信息和Alpha透明度信息拼接成一个视频文件（左右或上下排列）， 然后在H5页面通过Canvas API分离并渲染，实现透明度效果。

核心优势

  • 兼容性极佳 - 支持所有能播放H.264 MP4的浏览器（几乎所有现代浏览器）
  • 单文件传输 - 只需下载一个视频文件，减少HTTP请求
  • 文件体积小 - 相比原始GIF可减少50-80%的体积
  • 硬件加速 - 视频解码由浏览器底层优化，性能出色
  • 跨平台一致 - iOS、Android、桌面浏览器均可使用

适用场景

  • 需要在多种设备和浏览器上显示透明动图
  • 不想维护多个格式的视频文件（WebM、HEVC等）
  • 追求最佳兼容性而非极致压缩率
  • 需要对视频播放有更多控制（速度、跳转等）

💻 使用方法

步骤1: 转换GIF为拼接MP4

使用提供的转换脚本将GIF转换为拼接MP4：

# 安装依赖 npm install # 转换为水平拼接MP4（RGB在左，Alpha在右） node scripts/gif-to-split-mp4.js input.gif output.mp4 # 转换为垂直拼接MP4（RGB在上，Alpha在下） node scripts/gif-to-split-mp4.js input.gif output.mp4 --layout vertical # 自定义质量和编码参数 node scripts/gif-to-split-mp4.js input.gif output.mp4 --crf 20 --preset slow

步骤2: 在HTML中引入渲染器

<!-- 引入渲染器脚本 --> <script src="scripts/alpha-video-renderer.js"></script> <!-- 创建Canvas元素 --> <canvas id="myCanvas"></canvas>

步骤3: 初始化并播放

<script> // 创建渲染器实例 const renderer = new AlphaVideoRenderer({ videoSrc: 'path/to/output.mp4', canvas: document.getElementById('myCanvas'), layout: 'horizontal', // 或 'vertical' autoplay: true, loop: true }); // 播放视频 renderer.play(); // 控制播放 // renderer.pause(); // renderer.stop(); // renderer.setPlaybackRate(2.0); // 2倍速 </script>

📊 方案对比

方案 文件数量 浏览器兼容性 文件大小 实现复杂度
原始GIF 1个文件 100% (所有浏览器) 较大 极简单
WebM (VP9) 1个文件 ~70% (Chrome, Firefox, Edge) 小 (50-70%减少) 简单
HEVC Alpha 2个文件 ~30% (仅iOS 11+, macOS Safari) 很小 (60-80%减少) 中等
RGB+Alpha拼接MP4 1个文件 95%+ (H.264支持的所有浏览器) 小 (40-70%减少) 中等

各方案优缺点

WebM (VP9 with Alpha)

原生支持透明度 单文件 实现简单 不支持iOS 不支持Safari

HEVC with Alpha

文件最小 iOS硬件解码 需要两个文件 仅iOS/macOS 兼容性差

RGB+Alpha拼接MP4 (本方案)

兼容性最佳 单文件 跨平台一致 可控性强 需要Canvas渲染 略大于HEVC

🔬 技术原理

1. 视频编码阶段 (FFmpeg)

使用FFmpeg的filter_complex将GIF的RGB和Alpha通道拼接：

# 水平拼接示例 [0:v]split=2[rgb][alpha]; # 分离成两路 [alpha]alphaextract[a]; # 提取alpha通道 [rgb][a]hstack # 水平拼接（左RGB，右Alpha）

2. Canvas渲染阶段 (JavaScript)

渲染器在每一帧执行以下操作：

  1. 从视频中读取当前帧
  2. 分离RGB部分（左半部或上半部）
  3. 分离Alpha部分（右半部或下半部）
  4. 将Alpha部分的灰度值应用到RGB的Alpha通道
  5. 使用putImageData渲染到Canvas

3. 性能优化

  • 使用requestAnimationFrame确保流畅渲染
  • 复用临时Canvas避免重复创建
  • 视频解码由浏览器底层优化（硬件加速）
  • ImageData操作在GPU加速下性能出色

📚 API文档

AlphaVideoRenderer 类

构造函数参数

new AlphaVideoRenderer({ videoSrc: string, // 必需：视频文件URL canvas: HTMLCanvasElement, // 必需：目标Canvas元素 layout: 'horizontal' | 'vertical', // 可选：拼接布局（默认horizontal） autoplay: boolean, // 可选：是否自动播放（默认true） loop: boolean, // 可选：是否循环播放（默认true） muted: boolean, // 可选：是否静音（默认true） playbackRate: number // 可选：播放速度（默认1.0） })

方法

  • play() - 播放视频
  • pause() - 暂停视频
  • stop() - 停止并重置视频
  • setPlaybackRate(rate: number) - 设置播放速度
  • seekTo(time: number) - 跳转到指定时间（秒）
  • getCurrentTime(): number - 获取当前播放时间
  • getDuration(): number - 获取视频总时长
  • destroy() - 销毁渲染器，释放资源
